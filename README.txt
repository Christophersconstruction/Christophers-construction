# Christopher's Construction LLC — Free Website

Service area: Greenville, SC and surrounding areas.

Files:
- index.html — website
- style.css — design and responsive layout
- script.js — small footer script
- images/ — project photos

The site is static and can be hosted free on services such as GitHub Pages or Cloudflare Pages.
The contact form uses the business email via mailto and does not require a paid form service.
